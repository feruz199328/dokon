Do'kon admini

Tovarlar, narxlar va barcha yozuvlarni shu yerda o'zgartiring. O'zgarishlarni avval «Oldindan ko'rish» bilan faqat o'zingiz ko'rasiz. Mijozlar ularni faqat «Saqlash»dan keyin, 1–2 daqiqada ko'radi.

GitHub'ga ulanish

Saytni ochish ↗
Kalitni kiriting va «Ulanish»ni bosing.
Kalitni qanday olaman?
  1. github.com → o'ng yuqoridagi rasmingiz → Settings
  2. Pastda Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Nomi: dokon-admin, muddati: 1 yil
  4. Repository access → Only select repositories → dokon
  5. Permissions → Contents → Read and write
  6. Generate token → kodni nusxalab, shu yerga qo'ying

Kalitni hech kimga bermang. U faqat dokon reposini o'zgartira oladi.

Toifalar

Do'kon tepasidagi tugmalar. «Hammasi» tugmasi o'zi qo'shiladi. Tovari yo'q toifa saytda ko'rinmaydi.
